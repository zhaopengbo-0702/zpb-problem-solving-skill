# 深度讲解与知识迁移指南

在需要设计二级结论、三级推论、变形、多解或跨领域应用时读取。本文件提供选择准则，不是要求每道题使用全部内容。

## 把知识连成推导链

主干知识是原题证明实际使用的定义、定理和公式；二级结论是对这些知识做一次有说明的应用；三级推论是再推广、组合或改变条件后得到的结果。

采用下面的结构组织每条链：

1. 写清起点及成立条件。
2. 展示一次具体变形、代入、构造或推理。
3. 说明得到什么新结论。
4. 再改变一个条件，说明结论是否保留以及为什么。

例如，某条件只足以排除一种情况，就不能把它改写成另一种情况必然存在。能推出下界时，要区分“证明不能更低”和“构造例子达到这个下界”。

## 让生活类比真正帮助推理

类比应保持正在讲解的关系。例如：

- 守恒关系可以比作收支账本，指出每笔收入、支出或存量对应哪个量。
- 可相加的因素可以比作无组合折扣的套餐定价，说明额外搭配优惠何时使类比失效。
- 函数变化率可以比作仪表的速度读数；讲解局部变化与总变化时要分别说明。
- 算法中的移动窗口可以比作沿队伍滑动的一段观察范围，说明边界何时移动、为什么不遗漏。

不要只说“像生活中一样”。给一个足够小、可计算的例子，明确其对应关系。例子用来建立直觉，正式论证仍需单独完成。

## 设计三种有价值的变形

优先从以下维度选择三种实质不同的变形，而不是只换三个数字：

- 换条件：等号改不等号、范围扩大、去掉假设、只给局部条件。
- 换所求：求值改证明、存在性改构造、精确值改上界或下界。
- 换对象：整数改实数、有限改连续、单个对象改一组对象。
- 换表示：图形、表格、递推、函数、程序之间的转换。
- 换规模：小样例到一般参数，检验原方法是否仍成立。

每个变形都回答：题面哪里变了、底层关系哪里没变、旧方法哪一步需要修改、有没有新增边界。

## 选择实质不同的解法

不同方法应该改变关键表示、核心工具或论证路线。仅调换两行等式的顺序，不算一种新方法。

比较时交代：

- 哪条路线最自然地利用原条件。
- 哪条路线中间量最少、计算最短、错误风险最低。
- 哪条路线在条件变化后仍然可用。
- 哪条路线有助于理解但不适合在考场展开。

对算法题，时间开销是输入变大时需要做多少操作；空间开销是额外需要存多少东西。首次使用复杂度记号时，用循环次数或存储格数解释，不能只报一个符号。

## 跨领域联系的最低证据

每个应用按同一个顺序书写：

1. 原题中的关键关系是什么。
2. 抽掉题面故事之后，留下什么数学结构。
3. 在目标领域中，哪些对象分别对应原题的哪些量。
4. 给出明确的应用场景、公式或经典模型。
5. 写出必要假设，以及哪些现实因素会破坏对应关系。

优先考虑与具体结构相符的领域，不要为了凑足数量遍历所有学科。可供选择的结构与方向包括：

| 原题的结构 | 可以检验的应用方向 | 必须核对的区别 |
| --- | --- | --- |
| 相加分解 | 统计均值模型、推荐基线、成本分配 | 观测噪声、组合效应是否存在 |
| 守恒 | 物理收支、网络流、会计恒等式 | 系统边界、流入流出、单位 |
| 变化率与累计量 | 运动学、边际成本、连续概率 | 局部与整体、可导与可积条件 |
| 条件概率 | 诊断、分类、决策 | 基础发生率、条件方向、独立假设 |
| 最优选择 | 路径规划、资源调度、经济决策 | 可行约束、目标函数、局部与全局 |
| 递推或状态 | 算法、人口演化、库存管理 | 初始条件、状态是否包含必要信息 |

有噪声的数据，可能只有模型或平均水平近似满足关系。相同的字母、外观相似的公式，不能证明本质相同。若联系需要先取对数、线性近似或增加独立假设，必须把这一步说出来。

## 按学科调整核验重点

- 数学：定义域、分类、等价变形、边界、构造可行性、证明是否循环。
- 物理与工程：系统边界、模型假设、方向、单位换算、数量级和极限情形。
- 概率与统计：样本空间、条件方向、独立性、估计与真值、数据与模型。
- 算法与程序：输入约束、重复元素、空输入、下标、溢出、正确性和资源开销。
- 经济与最优化：变量含义、可行范围、约束是否有效、最优解是否存在。

非考试任务不必虚构考试分值。用户只要求局部讲解时，直接在那个范围内应用这些准则。
